# Expense Tracker
A simple browser-based expense tracker  where you can add and delete expenses, with a live running total. Built to practice DOM manipulation and array methods.
# Features
- Add and delete expenses
- Live running total calculation
- Data saved using localStorage
# Built With
- HTML5
- CSS3
- JavaScript (Vanilla)
# What I Learned
- DOM manipulation
- Array methods (reduce, filter)
- Working with localStorage
# How to Use
- Clone this repository
- Open index.html in your browser
- Strat adding your expenses!
# Future Improvements
- Add categories for expenses
- Add charts to visualize spending
- Export data as CSV
